# FlashLearn Evaluation Suite

Compares FlashLearn's structured card format against a standard LLM explanation
on a set of technical metrics suited for a formal ML systems paper.

## Setup

```bash
pip install -r eval/requirements.txt
```

The script reads your `GEMINI_API_KEY` from `.env.local` automatically —
no extra configuration needed if the app already runs.

## Usage

```bash
# 1. Start the FlashLearn dev server in one terminal
npm run dev

# 2. Run evaluation on default topics (in another terminal)
python eval/evaluate.py

# 3. Custom topics
python eval/evaluate.py --topics "Transformer attention" "CRISPR" "Nash equilibrium"

# 4. Custom API URL (production deployment)
python eval/evaluate.py --api-url https://your-app.vercel.app/api/generate

# 5. Save to a specific path
python eval/evaluate.py --output eval/results/my_run.json
```

Results are saved to `eval/results/eval_<timestamp>.json`.

## Metrics

| Metric | Description |
|---|---|
| **Output Tokens** | Tokens generated by the model |
| **Token Reduction %** | How much less FlashLearn generates vs. baseline |
| **Word Count** | Total words in the output |
| **Reading Time @200wpm** | Minutes at average adult reading speed |
| **Reading Time @250wpm** | Minutes at fast reading speed |
| **Flesch Reading Ease** | 0-100, higher = more accessible. Target: 60-70 |
| **Flesch Grade Level** | US grade level required to comprehend the text |
| **Lexical Diversity (TTR)** | unique_words / total_words — richer = higher |
| **Concept Coverage %** | % of baseline's 10 key concepts in FlashLearn (weighted) |
| **Information Retention** | LLM-as-judge score 0-100 on factual fidelity |

## Methodology

**Baseline**: Gemini (`gemini-2.5-flash-lite`) prompted in textbook/explanation mode —
analogous to asking ChatGPT "explain X comprehensively." Same model, different prompt,
so capability is controlled for and format is the independent variable.

**Token counting**: Gemini's `count_tokens` API for output tokens.
Output tokens are compared (not input) because the user reads output —
input tokens are an implementation detail.

**Readability**: Flesch-Kincaid (1975) formulas implemented with a rule-based
syllable counter (Young 1989 approximation). Accurate within ±0.5 grade level.

**Information fidelity**: LLM-as-judge pattern — Gemini extracts 10 key concepts
from the baseline, classifies each as COVERED / PARTIAL / MISSING in FlashLearn,
then assigns a 0-100 retention score. Weighted concept coverage =
(covered + 0.5×partial) / total × 100.
